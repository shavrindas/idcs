## 2. Qolgan ishlar / tekshirilmaganlar

1. **Backend'ni yangi kod bilan qayta ishga tushirish** — Mac'da eski jarayon
   o'chirilmay qolgan edi. Windows'da toza ishga tushirilsa, muammo yo'q.
2. **Widget hali emulator/telefonda sinalmagan** — faqat `flutter build apk --debug`
   muvaffaqiyatli o'tgan. Windows'da: emulator yoki telefonga o'rnatib, bosh ekranni
   bosib turish → Vidjetlar → IDCool → ekranga qo'yib tekshirish.
   Tekshirish kerak: kartalar ko'rinishi, LED shrift, app yopiq paytda jonli
   yangilanish, ↻ tugmasi, qayta yoqilgandan keyin tiklanish.
3. **Google Cloud sozlamasi** — web client `415636031627-asr8…` ning
   "Authorized JavaScript origins" ro'yxatiga `http://localhost:5173` va server
   manzilini qo'shish kerak, aks holda Google tugmasi chiqmaydi.
   Faqat app'da Google bilan bog'langan hisoblar kira oladi.
4. **Adminlarni 시설ga bog'lash** — `admin1`, `admin2` hech qaysi 시설ga bog'lanmagan
   (`facility_users` bo'sh), shuning uchun ular kirganda ro'yxat bo'sh chiqadi.
   App'dagi 시설 등록 (access code) orqali yoki DB orqali bog'lash kerak.
5. Login tokeni hali `dummy_token` — URL'dagi `facility_id`ni qo'lda o'zgartirishni
   server to'xtatmaydi. To'liq yopish uchun haqiqiy JWT kerak.

## 3. Windows'da ishga tushirish

```bat
:: Backend (markaz + 시설 node), idc_server_v2 papkasida
cd idc_server_v2
pip install -r requirements.txt
.testbat\test_scenario_1.bat
:: yoki qo'lda:
uvicorn src.app:app --host 0.0.0.0 --port 8900 --env-file .testbat\.env.center_fac --reload

:: Web konsol
cd idc_server_v2\src\module\ServiceWeb\webui\webservice
npm install
npm run dev            :: http://localhost:5173/webui/  (/api → 127.0.0.1:8900, ws ham)

:: App
cd idc_app\IDCS
flutter pub get
flutter run -d chrome --web-port 5300
flutter build apk --debug    :: widget sinovi uchun Android kerak
```

- App backend manzili: `idc_app/IDCS/lib/config.dart` (`_host`: web'da `localhost`,
  Android emulator'da `10.0.2.2`). Haqiqiy telefonda PC'ning LAN IP'si kerak.
- Ma'lumotlar bazasi masofada (`src/config/database.py`) — bu **production** ma'lumotlar
  (IDCool, 다온인터내셔널, 무한상사). Test yozuvlarini qoldirmaslik.
